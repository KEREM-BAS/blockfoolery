This policy covers the Blockfoolery website and Blockfoolery Uploader, a desktop tool that publishes Blockfoolery's own videos to Blockfoolery's own accounts on YouTube, TikTok, Instagram and Facebook.

What we collect

When the account owner connects an account, the tool receives OAuth access and refresh tokens and basic account identifiers (for example the YouTube channel ID, TikTok open ID and display name, Facebook Page ID and Instagram account ID). It also reads the publishing status of the videos it uploaded and, for planning, public information about published videos (such as titles and audience settings).

The tool does not collect data about viewers, followers or any other person, and has no sign-up for other users. The website does not use cookies, analytics or tracking.

How we use it

Tokens and identifiers are used only to upload Blockfoolery's videos, schedule or withdraw them, and check whether they were published. Nothing is sold, shared with third parties or used for advertising.

Where it is stored

Tokens are stored only in the macOS Keychain on the Blockfoolery computer. Publishing records (video IDs, links, status) are kept in a local database on the same computer. Nothing is stored on our own servers.

Google and YouTube

Blockfoolery Uploader uses YouTube API Services. By using it you agree to the YouTube Terms of Service; see also the Google Privacy Policy. Blockfoolery's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at Google security settings.

TikTok, Instagram and Facebook

Data from TikTok and Meta APIs is used only as described above. Access can be revoked in TikTok (Settings → Security → Apps and services) and in Facebook (Settings → Business integrations).

Retention and deletion

Disconnecting an account in the tool deletes its tokens from the Keychain. To ask for deletion of any data, write to the address below; we answer within 30 days.
